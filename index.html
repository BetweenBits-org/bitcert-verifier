Look up on a Bitcoin source of your choosing — never BitCert. Offline? Skip this; steps 1–3 already bind the record to that exact transaction id.

Uses the explorer's public REST API (/api/tx/<txid>). For regtest/private anchors use your self-hosted explorer. For mainnet/testnet, any public explorer works.
What this proves. (1) the record's leaf is included in the Merkle root; (2) that root is the value committed inside the transaction's OP_RETURN; (3) those OP_RETURN bytes belong to exactly that reveal_txid (double-SHA-256 of the raw transaction, computed here). Step 4 then shows that txid sits in a Bitcoin block.
