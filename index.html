On-chain confirmation

The only Bitcoin-dependent step. Look up on a source of your choosing — never BitCert. Offline? Skip it; the checks above already bind the record to that exact transaction id.

Uses the explorer's public REST API (/api/tx/<txid>). For regtest/private anchors use your self-hosted explorer. For mainnet/testnet, any public explorer works.
What this proves. (1) the record's leaf is included in the Merkle root; (2) that root is the value committed inside the transaction's anchor output; (3) those anchor output bytes belong to exactly that anchor txid (double-SHA-256 of the raw transaction, computed here). The on-chain confirmation step then shows that txid sits in a Bitcoin block.
